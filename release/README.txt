Silviozas Server (Remake) - ready-to-run build

1. Run silviozas-server.exe  (listens on 0.0.0.0:33131)
2. Point the proxy data11 config at this machine:
      PGTserver|YOUR_SERVER_IP
      PGTport|33131

Config files (edited live, no rebuild):
  serverdata.txt  -> maint|growtopia_server_ip|port  ([ServerData])
  send.txt        -> exe-console line (GT color codes)
  overlay.txt     -> in-game overlay line

Type a line in the server window + Enter -> instant overlay to all clients.
